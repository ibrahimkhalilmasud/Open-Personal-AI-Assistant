# AI-Personal-OS (Open-Personal-AI-Assistant)

A local-first Personal AI Operating System scaffold focused on user-owned knowledge.

## Phase 1 status

This repository now includes:
- architecture-aligned project structure
- single `.env` configuration contract
- SQLite table bootstrap for core entities
- local-first provider router priority
- vault scanner with required file type support
- Docker and cross-platform installer scripts
- beginner-oriented setup docs

## Quick start

1. Copy `.env.example` to `.env`.
2. Set `VAULT_PATH`.
3. Run:
   ```bash
   python main.py
   ```
